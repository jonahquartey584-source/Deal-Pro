# Deal Pro

Find UK rent-to-rent and serviced accommodation deals and analyse them with AI.

## Deployment

This project is deployed on Netlify.

- **Netlify project dashboard:** https://app.netlify.com/projects/deal-pro-app/overview
- **Live site:** https://deal-pro-app.netlify.app

Deploy from this folder with the Netlify CLI:

```sh
npm install
netlify deploy --prod
```

## Tutorial video

`assets/deal-pro-tutorial.mp4` is generated by `scripts/generate_tutorial.py`
and narrated by the ElevenLabs "Adam" voice. To rebuild it (on a Mac):

```sh
pip3 install pillow imageio-ffmpeg
ELEVENLABS_API_KEY=your-key-here python3 scripts/generate_tutorial.py
```

Then bump the `?v=` number on the tutorial video and poster in `index.html`
so browsers load the new version, and redeploy.
